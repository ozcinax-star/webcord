# Webcord Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Hesapsız, takma ad + oda kodu ile giriş yapılan, GitHub Pages'te çalışan sesli + yazılı sohbet sitesi.

**Architecture:** Statik ES-module sitesi, derleme yok. Saf mantık (`src/logic.js`) Node ile test edilir; ses (`src/audio.js`), oda/ağ (`src/room.js`) ve arayüz (`src/app.js`) tarayıcıda çalışır. Eş bulma Trystero (torrent stratejisi), ses mesh WebRTC.

**Tech Stack:** Vanilla JS (ES modules), HTML/CSS, Trystero (CDN, sabit sürüm), Node `node:test` (sadece mantık testi için).

**Spec:** `docs/superpowers/specs/2026-10-29-webcord-design.md`

## Global Constraints

- Sadece ses (video yok); `echoCancellation`, `noiseSuppression`, `autoGainControl` açık.
- 2-6 kişi hedefi; 6'dan fazlasında uyarı gösterilir, engellenmez.
- Oda kodu: 6 karakter, büyük/küçük harf duyarsız, normalize edilir; `?oda=KOD` linki kodu doldurur.
- Mesajlar `textContent` ile gösterilir (HTML yorumlanmaz), uzunluk sınırı 300 karakter.
- Aynı takma ad: görüntülemede "Ali (2)" şeklinde numara eklenir.
- Hiçbir veri saklanmaz; sunucu, hesap, derleme adımı yok.
- Klasör git deposu değil: commit adımları `git init` yapılırsa uygulanır, aksi halde atlanır.

## Review Focus

- Mikrofon izni reddedilirse: dinleyici olarak katılır, uyarı görünür (Task 3, 4).
- Boşluklu/küçük harfli/özel karakterli oda kodu girilirse normalize edilir veya reddedilir (Task 1).
- Mesajda `<script>` / HTML varsa metin olarak görünür (Task 1, 4).
- Aynı anda iki kişi aynı takma adla girerse çakışma çözülür (Task 1).
- Sekme kapanınca/eş ayrılınca audio öğesi ve liste girişi temizlenir (Task 3, 4).

## File Structure

- `index.html`: iskelet, iki ekran (giriş, oda).
- `style.css`: görünüm, mobil uyumlu.
- `src/logic.js`: saf fonksiyonlar (kod üretme/normalize, takma ad, mesaj temizleme).
- `src/audio.js`: mikrofon + konuşma algılama.
- `src/room.js`: Trystero sarmalayıcı (katıl, eşler, ses, mesaj).
- `src/app.js`: arayüz bağlama, ekran geçişi.
- `tests/logic.test.js`: mantık testleri.
- `README.md`: GitHub Pages yayın adımları, NAT notu.

### Task 1: Saf mantık (`src/logic.js`)

**Files:**
- Create: `src/logic.js`, `tests/logic.test.js`

**Interfaces:**
- Produces:
  - `generateRoomCode(): string` — 6 karakter, `ABCDEFGHJKLMNPQRSTUVWXYZ23456789` alfabesinden.
  - `normalizeRoomCode(input: string): string | null` — trim + büyük harf, boşluk/tire silinir; sonuç 6 karakter ve `[A-Z0-9]` değilse `null`.
  - `validateNick(input: string): string | null` — trim, 1-20 karakter, değilse `null`.
  - `uniqueNicks(entries: {id: string, nick: string}[]): Map<string, string>` — id → görüntü adı; çakışanlara katılım sırasıyla " (2)", " (3)" eklenir.
  - `cleanMessage(input: string): string | null` — trim, boşsa `null`, 300 karaktere kırpar.

- [ ] **Step 1: Testleri yaz** (`tests/logic.test.js`, `node:test`): `normalizeRoomCode(" ab-c 234 ")` → `"ABC234"`; `normalizeRoomCode("abc")` → `null`; `normalizeRoomCode("ab$d12")` → `null`; `generateRoomCode()` 50 kez çağrılınca hep `normalizeRoomCode` ile kendine eşit; `validateNick("  ")` → `null`, `validateNick("a".repeat(21))` → `null`, `validateNick(" Ali ")` → `"Ali"`; `uniqueNicks([{id:"a",nick:"Ali"},{id:"b",nick:"Ali"},{id:"c",nick:"Veli"}])` → a:"Ali", b:"Ali (2)", c:"Veli"; `cleanMessage("   ")` → `null`, `cleanMessage("x".repeat(400)).length` → 300, `cleanMessage("<b>hi</b>")` → `"<b>hi</b>"` (kaçışlama arayüzde `textContent` ile yapılır).
- [ ] **Step 2: Çalıştır, başarısız olduğunu gör**
  Run: `node --test tests/`  Expected: FAIL (modül yok).
- [ ] **Step 3: `src/logic.js` içinde yukarıdaki beş fonksiyonu uygula** (named export, ES module; `package.json` yok, bu yüzden test dosyası ve kaynak `.js` ES module olarak çalışsın diye kök dizine `{"type":"module"}` içeren `package.json` ekle).
- [ ] **Step 4: Çalıştır, geçtiğini gör**
  Run: `node --test tests/`  Expected: tüm testler PASS.
- [ ] **Step 5: Commit** (git varsa) — `feat: add pure room/nick/message logic`

### Task 3: Ses ve oda katmanı (`src/audio.js`, `src/room.js`)

**Files:**
- Create: `src/audio.js`, `src/room.js`

**Interfaces:**
- Consumes: `uniqueNicks`, `cleanMessage` (Task 1).
- Produces (`audio.js`):
  - `getMic(): Promise<MediaStream | null>` — kısıtlamalar Global Constraints'teki gibi; reddedilirse/aygıt yoksa `null`.
  - `watchSpeaking(stream: MediaStream, onChange: (speaking: boolean) => void): () => void` — `AnalyserNode` ile ses seviyesi eşiği; durdurma fonksiyonu döner.
- Produces (`room.js`):
  - `joinRoom(opts: {code: string, nick: string, stream: MediaStream | null, handlers: {onPeers(list: {id: string, name: string}[]): void, onStream(id: string, stream: MediaStream): void, onPeerLeave(id: string): void, onMessage(name: string, text: string): void}}): {send(text: string): void, setMic(enabled: boolean): void, leave(): void, selfId: string}`
  - Trystero uygulama kimliği `"webcord-v1"` (oda adı `code`), torrent stratejisi, CDN'den sabit sürümle içe aktarma (uygulama sırasında `npm view trystero version` ile mevcut kararlı sürüm doğrulanıp sabitlenir).
  - Takma adlar `makeAction("nick")` ile yayınlanır; `onPeers` her değişimde `uniqueNicks` sonucuyla çağrılır (kendi girişi dahil değil).
  - `setMic(false)` yerel ses parçasını `enabled=false` yapar.

- [ ] **Step 1: `audio.js`'i uygula.** Doğrulama (tarayıcı konsolu, Task 4 öncesi): bir sayfada `getMic()` mikrofon izni ister; reddedince `null` döner.
- [ ] **Step 2: `room.js`'i uygula:** `joinRoom` içinde `addStream`/`onPeerStream`, `onPeerJoin` (takma ad gönder), `onPeerLeave` (listeden sil + `onPeerLeave`), mesaj eylemi (`cleanMessage` ile gelen metni de temizle).
- [ ] **Step 3: Commit** (git varsa) — `feat: add audio and room layers`

**Files:**
- Create: `src/app.js`

**Interfaces:**

- [ ] **Step 1: Giriş akışı:** sayfa yüklenince `?oda=` varsa `#code`'u doldur. "Oda oluştur" → `generateRoomCode()` ile kodu doldurup katıl. "Katıl" → `validateNick` + `normalizeRoomCode`; geçersizse `#join-error`'a Türkçe mesaj yaz, katılma.
